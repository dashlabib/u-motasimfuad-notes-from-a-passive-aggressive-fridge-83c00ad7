One funny passive-aggressive note from a smart fridge, for the make.fun bounty "Notes From a Passive-Aggressive Fridge". The joke is the yogurt: it expired on Tuesday, and instead of quietly throwing it away, the fridge kept it on display as a lesson. The sting lands in the last few words — the appliance, which never forgets a date and never lets anything go, is lecturing its owner about commitment. The fridge is the reliable one in this relationship, and it knows it.

## Run it

```bash
python3 main.py
```

This validates the note (1–200 characters, not only whitespace, single line) and writes it with no trailing newline to `/output/entry.txt` and to the repo-root copy `entry.txt`, verifying both by read-back.

## Entry

> Your yogurt expired Tuesday. I didn't throw it out — I wanted you to see what commitment looks like.
